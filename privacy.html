Privacy Policy for PixHarbor Publisher

Last updated: October 13, 2026

Overview

PixHarbor Publisher is a browser extension workflow tool that helps users prepare and publish Pinterest pins from images they select. The app is designed to operate locally in the user's browser whenever possible.

Data processed by the app

  • Selected image URLs and basic image metadata.
  • Current webpage title, URL, and available page metadata.
  • User-entered pin title, description, hashtags, alt text, board selection, and affiliate or destination link.
  • Pinterest access token only when the user provides it for Pinterest API publishing.

How data is used

Data is used only to prepare Pinterest pin drafts, load the user's own Pinterest boards, and publish pins after the user chooses to do so. PixHarbor does not sell, rent, or share personal data.

Storage

Settings and draft preferences may be stored locally in the browser. PixHarbor does not operate a remote server for collecting user browsing data or selected images.

Pinterest API

When the user connects Pinterest API access, PixHarbor uses the provided access token to read the user's own boards and publish pins to the selected board. Publishing happens only after direct user action.

Third-party websites

Source images remain hosted by their original websites. Pinterest publishing is handled through Pinterest's official API or Pinterest's own create-pin flow.

Contact

For questions about this policy, contact the app owner through the GitHub account hosting this page.
